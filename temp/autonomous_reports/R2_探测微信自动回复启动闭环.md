## ✅ 最小操作手册

### 方式A：用户手动启动（推荐）
```powershell
# 1. 打开新PowerShell窗口
# 2. 执行启动器
F:\dev\GenericAgent\temp\wechat_reflect_project\start_wechat_reflect.ps1
```
启动器自动完成：
- 杀旧进程（精确匹配命令行含 `wechat_reflect.py` 或 `start_wechat_reflect.ps1` 的进程）
- 归档旧 `latest.log` → `logs/archive/wechat_reflect_时间戳.log`
- 加载 `.env` 环境变量
- 激活 `.venv`（清除父VIRTUAL_ENV避免冲突）
- 前台运行 `python wechat_reflect.py`（不用Tee-Object，脚本内log_line写日志+stdout）

### 方式B：GA代理启动（需绕过PS1）
```python
# 按SOP第44行，PS1自杀逻辑会杀匹配进程，需直接启动：
import subprocess
work_dir = r"F:\dev\GenericAgent\temp\wechat_reflect_project"
subprocess.Popen([
    'powershell', '-NoExit', '-Command',
    f'cd "{work_dir}"; Remove-Item Env:\\VIRTUAL_ENV -ErrorAction SilentlyContinue; & "{work_dir}\\.venv\\Scripts\\Activate.ps1"; $env:PYTHONUNBUFFERED="1"; python wechat_reflect.py'
])
```

4. 确认后自动开始轮询

- 归档日志：`wechat_reflect_project/logs/archive/`

### 停止
